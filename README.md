# CPU-S2 v2.5.1

Mac / 黑苹果上的 CPU 频率观察工具。在本机运行轻载、单线程和多线程检测，查看频率估算、阶段统计与频率分布。

- 支持 macOS 11 起，提供 `x86_64` + `arm64` 通用应用。
- 检测无需管理员权限，不安装 kext、不改 EFI、不写系统文件。
- 默认使用内建计时探针；Intel 上已有可执行 PowerLog 时，可选择兼容来源。
- 内建探针未经绝对精度标定，不能凭一次检测诊断 CPU 电源管理。

## 开始使用

把 `CPU-S2.app` 拖进「应用程序」。机型信息完整显示机型标识符、处理器、系统版本与构建号、核心/线程、标称基频和 XCPM 上限。打开后点击「开始检测」；运行中可点「停止检测」，程序会清理本次负载并保留上次完整结果。

界面分为「检测概览」和「频率详情」：概览呈现结论、三种负载结果及分布图，详情提供分箱与采样统计。检测操作固定在顶部，采样来源收进设置。沿用原版浅灰底、白卡、浅灰细边框及粉蓝配色，标题、正文与辅助文字统一为柔和的三级灰色；状态标签垂直居中。默认宽度 800，最小可缩至 720。

每轮约 30 秒，含预热。未完成检测时隐藏结果区，完成后再显示结果；取消重测则恢复上次完整结果。窗口支持缩放与滚动；检测结束后可按阶段查看结果和频率分布。

Intel 的「核心 / 线程」分两行显示大核（P）、小核（E）和系统线程数。系统能完整报告 Performance / Efficiency 级别时直接采用；否则精确匹配已核实的 Intel 型号规格，并明确标为「标称」。例如 i7-12700K 显示「标称 8 大核 + 4 小核」及「12 核 / 20 线程」。未知型号保留总核数与线程数，不按代数或线程差值猜核型。

总核心数优先采用 `hw.physicalcpu_max`，避免部分 Intel 黑苹果将当前物理核心数误报为大核数；线程数采用 `hw.logicalcpu`。鼠标停在核心信息上可查看当前/最大计数、规格来源及链接。型号标称大小核数与 BIOS / EFI 当前启用数量可能不同，禁用小核或超线程后不会用型号最大线程数替换当前线程数。Apple Silicon / Rosetta 不使用 Intel 型号目录。这些信息也会保留在 TXT 摘要与 JSON 报告中。

## 自动更新

默认启用自动更新：启动后检查 GitHub 最新正式 Release，应用持续运行时每 6 小时复查；启动检查在 1 小时内复用上次成功检查时间。发现新版后自动下载 `CPU-S2-v版本号.zip`，核对 GitHub 提供的 SHA-256、ZIP 内容、应用版本、架构和签名完整性，然后替换并重启。

GitHub API 限流或网络暂时无法访问 API 时，会改用公开 Release 地址及该版本的 `SHA256SUMS.txt`；两条路径均固定为本项目仓库并执行相同的安装包校验。

检测、导出或其他模态操作尚未结束时，会先保留已下载更新，结束后再安装。重启前会把当前完整检测报告保存到 `~/Library/Application Support/CPU-S2/Reports/`。更新器等待旧进程退出，保留旧应用备份，并确认新版启动；替换或启动失败时恢复旧版。失败记录位于 `~/Library/Logs/CPU-S2/Updater.log`。

在「设置」或「CPU-S2」菜单中可手动检查更新、关闭自动下载与重启。应用需位于当前用户有权替换的可写目录，建议安装到「应用程序」；在只读 DMG 中运行时会保持当前应用并提示先安装。自动更新访问公开 GitHub Release，不使用本机 GitHub token，也不上传检测数据。

发布更新时必须把 `./package.sh` 生成的应用 ZIP 上传到同一正式 Release；仅有 DMG 或源码归档时不会自动安装。当前使用 ad-hoc 签名，校验用于确认应用完整性，不能替代 Apple 开发者签名与公证。

| 阶段 | 默认内建模式的负载 | 采样时长 |
|---|---|---|
| 轻载探测 | 约每 200 ms 运行一次 4 ms 探针，会唤醒 CPU | 8 秒 |
| 单线程计算 | 探针自身连续计算 | 6 秒 |
| 多线程计算 | 逻辑线程数 − 1 个 `yes` 进程，加探针线程 | 12 秒 |

实际占用率受调度和后台程序影响。以上是计算负载，不能视为所有执行单元满载的压力测试。停止或退出时只清理本次检测创建的子进程。

应用使用 ad-hoc 签名，未经 Apple 开发者签名与公证。首次打开被系统拦截时，先双击应用，再到「系统设置 › 隐私与安全性」找到 CPU-S2 的记录，点击「仍要打开」，按系统提示完成首次打开。

## 怎样理解结果

内建探针通过整数指令依赖链和墙钟计时估算当前线程的执行频率。微架构、循环开销、抢占、迁核和调频都会影响读数，线程也不保证固定在某颗核心。轻载探测仍会唤醒 CPU，不能代表真正空闲时的频率。

Apple Silicon 的内建结果未区分 P/E 核或簇，不使用 Intel 的基频判定。

已有 PowerLog 的 Intel 机器可选择兼容来源，无需另外安装。此时轻载和多线程使用其封装平均频率，单线程仍为探针估算；来源不可用时会提示回退。温度、功耗按邻近采样时间配对，只在读到有效值时显示。

「最高温」是有效样本中的最高已读温度，不能代表两个采样点之间的真实峰值。读不到温度时显示缺失，不使用结束温度回填历史记录。

## 统计口径

统计和图表使用同一套有效样本。非有限频率和超出合理范围的读数会被剔除，并保留原始样本、剔除数量与原因。

- **中位数**：偶数个样本取中间两项的平均值。
- **P90**：nearest-rank，排序后取第 `ceil(0.9 × n)` 项，从 1 计数。
- **100 MHz 分箱**：将有效频率归入最近的箱中心。命中箱数表示本次观察到的分布，不是硬件 P-state 数。
- **Intel 结论**：在样本足够时，结合 P90 和重复高频样本，区分「观察到高于基频」「本次未观察到」「数据不足」。不会只凭一个峰值下结论。

Intel 的判定门槛为 `基频 + max(100 MHz, 基频 × 5%)`。5% / 100 MHz 是决策带，不是探针精度或统计置信区间。缺少基频或有效样本不足时不作否定判断。`CPU_Speed_Limit` 是系统报告的限制百分比，不能换算为当前实际频率。

## 复制与导出

「复制摘要」复制硬件、来源、阶段统计和结论的文字摘要。「导出报告…」支持以下格式：

| 格式 | 内容 |
|---|---|
| TXT | 便于阅读和分享的检测摘要 |
| CSV | 逐样本记录，便于自行分析 |
| JSON | 完整检测数据，含原始样本和剔除记录 |

## 编译与验证

需要 Xcode 命令行工具和 Python 3。在本目录运行：

```bash
./Tests/run.sh     # 无负载回归：61 项引擎检查、169 项报告检查、29 项核心拓扑检查
./Tests/run-ui.sh  # 234 项界面状态与机型字段检查，不加压
./Tests/run-update.sh          # 版本、GitHub 元数据、SHA-256、ZIP 边界与解压校验
./Tests/run-update-fallback.sh # Release 地址与校验清单的限流备用路径
./Tests/run-installer.sh       # 私有临时应用中的替换、回滚与启动确认
./Tests/run-update-manager.sh  # 离线网络生命周期与取消流程
./build.sh         # 编译并签名，产出 build/CPU-S2.app 通用应用
./package.sh       # 产出 DMG、应用 ZIP 与 SHA256SUMS.txt
```

构建在临时位置完成编译和校验后发布应用，并归档已有旧版应用。

```bash
./build/CPU-S2.app/Contents/MacOS/CPU-S2 --preview   # 固定示例数据，检查布局
./build/CPU-S2.app/Contents/MacOS/CPU-S2 --selftest  # 实际运行整轮负载并导出界面快照
```

快照默认写入临时目录，可通过 `CPUS2_SNAPSHOT_DIR` 指定已存在的输出目录。预览模式不产生检测负载，其示例结果不能用于判断本机性能。

## 文件与卸载

PowerLog 模式会使用临时 CSV，处理后清理。导出报告写入自行选择的位置；界面检查会写 PNG 快照。自动更新会临时下载和解压安装包，完成后清理；旧应用备份保存在安装目录旁的隐藏 `.cpus2-update-*.backup` 文件夹。

卸载时删除应用即可。如需清除旧版遗留偏好，可删除 `~/Library/Preferences/com.cpus2.CPU-S2.plist`。

核心代码：`Sources/Engine.swift`（采样与统计）、`Sources/Probe.c`（探针与 SMC）、`Sources/main.swift`（会话控制）、`Sources/DashboardView.swift` / `Sources/DashboardComponents.swift` / `Sources/Views.swift`（界面）、`Sources/ReportWriter.swift`（独立报告导出）。
